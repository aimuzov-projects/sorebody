# Травмы в CrossFit / HIFT — сводка по PubMed

Источник: PubMed E-utilities (esearch / esummary / efetch rettype=abstract), поиск 15.10.2026.
Все цифры взяты из абстрактов (полные тексты не читались). Цитируются только реально полученные PMID.
Запросы: `crossfit injur* systematic review`, `crossfit injur* meta-analysis`,
`high-intensity functional training injur*`, `crossfit injury epidemiology`, `crossfit rhabdomyolysis`,
`crossfit injur* survey`, `crossfit injury shoulder`, `crossfit low back`, `crossfit[tiab] AND case reports[pt]`,
запросы по отдельным диагнозам (Achilles, pectoralis, SLAP, dissection, pelvic floor, hand/wrist, knee и др.).

Оговорки: почти все исследования — ретроспективные опросы с разным определением травмы, высоким риском
смещения (recall/selection bias). Отсюда огромный разброс частоты (0.04–36 на 1000 ч).
