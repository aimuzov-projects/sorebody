# 3D-модель главной

`public/model/body.glb` собрана из [BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html),
архив `isa_BP3D_4.0_obj_99.zip` (136 МБ) и `isa_element_parts.txt`. Три меша: `skin` (кожа целиком), `muscles`
(мышцы и сухожилия, без мышц глаза и языка, см. «Мышцы» ниже), `bones` (240 элементов: "bone organ", рёберные
хрящи, межпозвонковые диски, лобковый симфиз).

Лицензия: README базы с 2025 года говорит CC BY 4.0, а заголовки самих OBJ -- CC BY-SA 2.1 JP. На странице
"О справочнике" указана более строгая CC BY-SA 2.1 JP: производная модель тоже под ней.

Скрипты зависят от `@gltf-transform/core|functions|extensions@4.5.1` и `meshoptimizer@1.3.0`, в зависимости сайта не
входят: ставить в отдельную папку.

```bash
python3 -I config.py <папка со списками> <папка с OBJ> body.json 0.08 0.12 --skin
node build.mjs body.json body.glb
```

Аргументы `0.08 0.12` -- доля треугольников мышц и костей после упрощения, кожа -- 0.3. Рядом с GLB появится
`body.anchors.json` с центрами суставов, их надо перенести в `src/frontend/scene/zones.ts`.

## Детальные куски зон

Общий план показывает только `body.glb`. Когда зону открывают (или наводят на её строку или точку), сцена догружает
кусок `public/model/detail/<зона>-<сторона>.glb`: все слои в сфере 1,25 радиуса зоны вокруг её точки. Внутри этой
сферы базовые мышцы и кости не рисуются, их заменяет кусок (`uCut` в `dissolve.ts`). Нервы лежат отдельно в
`<зона>-<сторона>.nerves.glb`, слабые устройства их не грузят. `index.json` говорит сцене, какие куски есть.

`detail.py` собирает конфиги кусков: кости, мышцы, хрящи, артерии и вены BodyParts3D (у поясницы без вен живота) и
слои Z-Anatomy, если передать их папку. `offset` берётся из лога сборки фигуры (строка `bounds ... offset`), чтобы кусок
лёг в её координаты. `build.mjs` по `clip` оставляет треугольники в сфере, а слои Z-Anatomy ещё и обрезает по коже
BodyParts3D (`skinClip`, `skin-test.mjs`): что вышло наружу, висело бы над телом. Последний аргумент `detail.py` --
доля треугольников, `1` -- без упрощения. Точки и радиусы зон в `detail.py` и `zones.ts` должны совпадать, это
проверяет `src/frontend/scene/detail.test.ts`.

### Мышцы

Крупные мышцы в BodyParts3D лежат частями: дельтовидная и большая грудная -- "zone of muscle organ", четырёхглавая,
двуглавые и икроножная -- "head of muscle organ", трапециевидная -- части без своей категории. `config.py` и `detail.py`
берут их вместе с "muscle organ" и "tendon". `build.mjs` пишет каждой вершине мышц номер мышцы (`_PART`, названия по
номерам -- в extras меша) и направление волокон (`_FIBER`, главная ось мышцы). По ним шейдер рисует волокна и подсвечивает
мышцы травмы, а `index.json` хранит списки мышц кусков для теста карты травм (`INJURY_LAYER` в `zones.ts`).

В раскрытой зоне растворяется только кожа. Травма глубже мышц (`deep`) раскрывает в мышцах малую сферу, в ней видны
связки, кости, сосуды и нервы. Мышечная травма подсвечивает свои мышцы, а если они лежат под другими (`peel`), сфера
снимает только мышцы над ними.

### Связки, мениски и нервы из Z-Anatomy

В BodyParts3D нет менисков, крестообразных и коллатеральных связок, суставных губ и нервов конечностей. Их берём из
[Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy) (CC BY-SA 4.0, `Z-Anatomy.zip` → `Startup.blend`)
через Blender 5.2: `z_anatomy_export.py` выгружает их с применёнными модификаторами, `z_align.py` подгоняет к костям
BP3D по каждой зоне (ICP с масштабом по костям сустава в радиусе зоны). Внутреннее ухо и почку (NC-лицензии) и
структуры пальцев (у Z-Anatomy они согнуты иначе) скрипт не берёт. Ещё он берёт мышцы, которых нет в BodyParts3D: широчайшую, многораздельную, квадратную мышцу поясницы,
внутреннюю косую, поперечную и прямую мышцы живота. Поясница совмещается по позвонкам L1-L5, а каждая вершина
переносится смесью подгонок ближних зон, чтобы длинные мышцы и нервы не рвались между зонами. Связки, мениски, губы и капсулы в куски идут все,
нервы -- только из списка `NERVES` в `detail.py`.

```bash
blender -b Startup.blend --python z_anatomy_export.py -- za-export
blender -b --factory-startup --python z_align.py -- za-export <папка с OBJ> za-aligned <offset x,y,z>
python3 -I detail.py <папка со списками> <папка с OBJ> detail/ <offset x,y,z> 0.5 za-aligned
for c in detail/*-*.json; do node build.mjs $c ${c%.json}.glb; done
cp detail/*.glb detail/index.json ../../public/model/detail/
```

## Шорты

`public/model/shorts.glb` -- модель «Distance Short Men» (fersmta, CC BY 4.0) с Sketchfab, посаженная на фигуру.
Архив модели скачивается вручную (нужен аккаунт Sketchfab), в репозитории его нет. `skin-obj.mjs` выгружает кожу
`body.glb` в OBJ, `shorts.py` в Blender берёт низкополигональную версию шорт, масштабирует её по талии и посадке,
отодвигает ткань от кожи и оставляет из текстур только карту нормалей (швы, резинка, панели).

```bash
node scripts/model/skin-obj.mjs public/model/body.glb skin.obj
blender -b -P scripts/model/shorts.py -- distance_short_men/scene.gltf skin.obj public/model/shorts.glb
```

Колыхание считает сцена: подол отстаёт от поворота фигуры пружиной (`uSwayTurn` в `dissolve.ts`).
